# 해설 쓰는 법

독자: 이 저장소를 만든(또는 같이 만든) 개발자. 특히 공부 중인 학생. 코드는 봤지만 "이 줄이 정확히 무엇을 하고 왜 필요한지"를 말로 설명하는 데 약하다. 목표는 **AI 없이 코드를 보고 이해하는 능력**과 **어떤 질문에도 답할 수 있는 상태**.

## 문체

- 한국어 해요체. 짧은 문장. 한 문장에 한 가지.
- 처음 나오는 용어는 `[[용어-id]]` 로 사전에 잇고, 문장 안에서도 쉬운 말로 한 번 풀어 준다.
- 코드 이름은 그대로(`addTodo`, `getTodos`), 뜻은 우리말로("할 일 하나를 서버에 보내는 함수").
- "무엇을"보다 **"왜"** 를 한 번 더. 이 줄이 없으면 무엇이 깨지는지.
- 예시 값을 쓴다: `'우유 사기'`, `id 1`, `http://localhost:3000/todos`.
- 줄 번호로 짚는다: "14번 줄에서 앞뒤 공백을 잘라요".
- 비유는 덩어리 설명에 가끔만. 줄 해설은 사실만.

## 줄 해설 (lines)

- **코드가 있는 줄마다 하나.** 빈 줄 · 괄호만 · import · 주석 줄은 생략해도 된다(import 는 엔진이 자동 설명).
- 한두 문장. 그 줄의 문법 + 그 줄이 하는 일.
  - 좋음: `"[[spread]] 로 새 할 일을 기존 목록 앞에 붙인 새 배열을 만들어요. 기존 배열을 고치지 않아야 React 가 바뀐 걸 알아채요."`
  - 나쁨: `"사용자를 찾는 코드입니다."` (문법도, 이유도 없음)
- 긴 한 줄(체인 · 삼항 · 람다)은 순서대로 풀어 준다: "① … ② … 그래서 …".
- 스타일 코드(StyleSheet · CSS)는 화면에서 어떻게 보이는지로: "글자 18 · 굵게 → 카드 제목".

## 덩어리 (blocks)

- 함수 · 메서드 하나, 또는 의미 있는 묶음 하나(필드들, 스타일 한 부분, 설정 한 구역). 3~40줄 정도.
- `title`: 무엇인지 + 무엇을 하는지. `"addTodo — 할 일 하나 추가"`, `"POST /todos — 검사하고 만들기"`.
- `explain`: 첫 문장 = 한 줄 요약(페이지에서 굵게). 이어서 흐름 · 이유 · 누가 부르는지 2~5문장.
- `sig`: 함수면 들어오는 것 · 나가는 것을 우리말 + 타입으로.

## "주의:"

- **직접 열어 확인한** 버그 · 위험 · 문서와 코드의 어긋남만. 줄 해설 앞에 `주의:` 를 붙인다.
- 무엇이 · 언제 · 어떻게 깨지는지 구체적으로: `"주의: 오류 문구를 넣기만 하고 지우는 곳이 없어서, 다음에 추가가 성공해도 옛 오류 문구가 계속 보여요."`
- 남의 폴더 문제는 고치지 않고 review.json 의 requests 에 "무엇을 왜 (파일:줄)" 로 남긴다.

## 따라가기 이야기

- 사용자 행동 하나(버튼 누르기, 서버 켜기, 학습 명령 실행)에서 시작해 눈에 보이는 결과까지.
- 단계 = "누가 무엇을 해요". 파일을 건너갈 때는 `carry` 에 실제로 넘어가는 값을 적는다(HTTP 본문, 객체 모양, 파일 이름).
- 같은 파일을 여러 번 들르면 그대로 둔다(엔진이 "이 파일 n번째 방문"을 보여 준다).

## 에이전트에게 맡길 때 붙일 지시문 (그대로 복사해서 쓴다)

```
너는 <저장소 경로> 저장소의 아래 파일들에 한국어 줄별 해설을 쓴다. 저장소 파일은 절대 고치지 않는다.
결과는 <작업폴더>/annot/<이름>.json 하나에 배열로 쓴다 (Write 도구 사용 — bash heredoc 은 역슬래시가 사라진다).
모양은 references/schemas.md §2, 문체는 references/writing.md 를 따른다.
- 덩어리는 구간 첫 줄부터 끝 줄까지 빈틈 · 겹침 없이 이어져야 한다.
- 코드가 있는 모든 줄에 줄 해설. [[용어-id]] 는 terms.json 에 있는 것만 쓰고, 새로 필요한 용어는 마지막 답변에 id · 이름 · 패턴 · 묶음으로 따로 적는다.
- "주의:" 는 코드를 보고 확인한 문제만. 비밀 값(키 · 토큰 · 클라이언트 ID · .env 값)은 해설에 옮겨 적지 않는다.
- 끝나면 node <스킬>/engine/check.js <작업폴더> annot/<이름>.json 를 돌려 OK 와 "줄 해설 없는 코드 줄 0" 을 확인하고, 결과 숫자만 보고한다.
파일: <목록, 구간이면 from~to>
```
